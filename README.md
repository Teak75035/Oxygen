## 痛点是什么？
- 老师点名耗费大量时间精力？

- 经常只有少数人能参与课堂？

- 传统点名软件周期随机明显？

- 为什么他们总是不会被抽到？

- ......

现在，这一切都将成为历史。

因为，这也是我们要解决的。

## 我们的历程
- 随机抽号软件 v1.0-1.6
  > 依赖于 CoCo Framework 和 JavaScript，
  > 周期性过于明显，使用极其繁琐。

- 随机抽号系统 v2.0-2.4
  > 引入不放回机制，保证公平性。
  > 但这就够了吗？我们需要更深入些。

- Oxygen 3.0 Beta
  > 基于 Python 3.12 开发，架构更稳定，一触即发更便捷。
  > 但这只是起点。

- Oxygen 3.2 Beta
  > 引入超整型插值算法，有效降低周期性。

- Oxygen 3.3 Beta
  > 引入种子扩域算法，周期性进一步降低。

- Oxygen 3.4 Beta
  > 引入数据库加密机制，数据公开更上一层楼。
  > 小动作，无处藏。

- Oxygen 3.6 Beta
  > 引入直方加权算法，公平再升级。

- Oxygen 3.7 Beta
  > 删库了。

## 为什么？？
大量的算法堆积导致程序臃肿；

Python的解释器效率低下；

程序的扩展使系统越来越不稳定......

我们需要一个更快、更便捷、更通用的解决方案。

下面，为你介绍：

# Oxygen 4 Java Edition

## 下载使用，一气呵成
- Oxygen 3.x
  > Python 工程项目，部署复杂，需要安装 Python 环境。

- Oxygen 4.x
  > Java 打包程序，下载，安装，一步到位

## 全新引导式向导
设置向导替你搞定一切，

解放双手，开箱即用，

你的时间值得更好的安排。

## 新底层，快快快快到飞起
Java 底层，编译运行速度大幅提升，

对比 Python 运行效率提升900%！

科技不需要等待。

## 专用 EKV 数据库，安全高效
独创 EKV 数据库格式，拒绝破解数据库，

小动作无处遁形。

## 插件系统，你来定义
支持全新 opp 插件，也要兼容旧 py 插件。

换了语言，不换习惯。

## HUD……？
HUD 系统，显示课堂信息，

课程表、时间、日期、天气、倒数日，

作业、考试计时、上课下课提醒，

甚至是交互式HUD和通知接口，一切皆有可能。
